# Prompt Rules

Structure prompts as scene, palette, surface, light, camera, composition,
confirmed ingredients, protected-layer contract, and negative constraints.

Every background prompt must include:

```text
do not generate any product, container, bottle, jar, box, packaging, label,
logo, text, letters, watermark, person, hand or face
```

Also require a clear empty central placement area for the real supplied product.
Use one targeted change per regeneration. Never invent claims, ingredients,
certifications, measurements, or performance data.
