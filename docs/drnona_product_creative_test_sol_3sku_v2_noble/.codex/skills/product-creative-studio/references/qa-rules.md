# QA Rules

Check product fidelity, logo/label preservation, package geometry, product
count, visibility, scene relevance, shadow, surface contact, background text,
clutter, harmony, edge quality, dimensions, aspect, duplicates, hallucinated
packaging, crop, added accessories, and category.

Use PASS only when protected product fidelity and output integrity pass. Use
REVIEW for ambiguity or low-confidence classification. Use REJECT for changed
packaging, missing/cropped product, duplicate product, or fidelity below the
review threshold.

Never publish REJECT. Never describe REVIEW as approved.
