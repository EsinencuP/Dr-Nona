# G08 / G10 — editorial media и анонсы

Дата: 2026-09-06. Продолжение [исходного visual audit](VISUAL_DESIGN_GAP_AUDIT_2026-09-05.md). Scope: устранение G08 и G10 по прямому запросу пользователя. Исходные datasets, переводы, claims и release approval не изменены.

## Подтверждённые причины и исправления

| ID / severity | Surface / viewport | Before | After | Why |
|---|---|---|---|---|
| G08 / P2 | Editorial cards, статьи, RU/RO, 320–2048 и landscape | Cloudinary `w_1200,h_400,c_fill` сначала обрезал оригинал; CSS `cover` повторно обрезал его под карточку. Badge и hover могли перекрывать/срезать надписи | Тот же официальный asset запрашивается с `f_auto,q_auto,w_1200,c_limit`. Artwork — `contain`; статья — естественное соотношение сторон. Тип публикации перенесён в строку даты; artwork не масштабируется при hover | Дата и время Zoom, надписи webinar/anniversary и края афиш сохраняются. CSS не может восстановить crop, уже сделанный сервером |
| G08 / P2 | About landing и galleries, RU/RO, mobile/tablet/desktop | Полосы высотой 108/142/150 px с `cover` обрезали лица; gallery имела фиксированную высоту | Портреты истории, основателей и науки — `contain` в mineral surface; более высокий stage, без hover zoom. Gallery использует исходный ratio и не растягивает соседние изображения по высоте | Сохраняется весь доступный исходный кадр, включая групповой портрет; для неизвестного focal point не требуется угадывать crop |
| G10 / P2 | Все 114 действующих news/blog records, обе UI locales | Один English marketing meta-description выдавался за анонс каждой публикации | Точно распознанный boilerplate скрывается через `getOfficialPageDescription`; карточка и статья корректно работают без excerpt | Заголовок, дата, изображение и действие снова различают материалы; новый текст не выдумывается |

Source identity, `alt`, title, body, source link и порядок публикаций сохранены. Доставка изображения меняется только для известного Cloudinary account `drnona-com` и путей `news`, `blog`, `pages`. Product assets, другие providers и неизвестные URL shapes не переписываются.

Reference principle: разделение display modes по роли изображения из первоначального анализа Shopware и разных image ratios из Solace. Это применение принципа сохранения информации, без копирования storefront flow в информационный каталог.

## Политика ролей и границы G10

- `/news/inactive-cleanup`: вручную просмотренное фото без обязательной надписи, допускает `cover` и небольшой hover zoom.
- Остальные editorial assets: консервативный `artwork` mode, полный кадр. Это безопасное поведение для неизвестной роли, а не заявление о ручной классификации всего архива как афиш.
- About: здание — photo; история, основатели, наука — portrait с полным исходным кадром. Gallery — естественный ratio.
- Motion использует существующие CSS tokens. Reduced-motion правила продолжают отменять transform. Новых dependencies нет.
- Exact boilerplate найден в 116 raw official records, из них 114 действующих news/blog. Suppression допускает различия whitespace, но не блокирует любой English текст по языку или короткому префиксу.
- Исходный English meta-description остаётся в dataset для traceability. Новых summaries и переводов нет; ранее существовавший claims gate продолжает применяться независимо от suppression.
- Original-language article title/body сохраняют `lang="ru"`; Romanian shell и `Citește` сохраняются. Canonical/original-language route policy и SEO generation не менялись.

G10 закрывается выбранным вариантом из исходного audit: убрать бесполезный общий excerpt. Написание индивидуальных source-backed анонсов может быть отдельной редакторской задачей; это не скрытое одобрение переводов и не закрытие P0-LOCALE.

## Самокритика и ограничения

Что всё ещё выглядит как generic template: однородная структура архива и неодинаковое качество старых растровых материалов. G10 убирает повторяющийся маркетинговый шум, но не делает каждый материал уникальной редакторской композицией. Это не причина выдумывать source summaries.

Полный кадр оставляет спокойное поле вокруг некоторых изображений. Это осознанный компромисс сохранности надписей и лиц. Старые About thumbnails остаются невысокого исходного разрешения; `c_limit` не пытается выдать upscale за новый качественный источник. Новые официальные masters и rights approval потребуют отдельного решения.

В промежуточной итерации увеличенный portrait stage растягивал соседние карточки; высота desktop stage ограничена. При проверке mobile photo обнаружен конфликт intrinsic aspect-ratio с узкой grid column; добавлены `min-width: 0`, сброс ratio в photo row и regression assertion на overlap. Эти промежуточные варианты не являются финальным результатом.
